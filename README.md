# Boas Práticas de Desenvolvimento de Software

Repositório para armazenar conteúdo do Projeto Intagrador "Boas Práticas de Desenvolvimento de Software".

## Tema do Projeto
### Reserva de Salas

Descrição

Desenvolvimento de uma aplicação web para o agendamento de salas de
reunião em uma empresa, permitindo verificar a disponibilidade e evitar
conflitos de horário entre os colaboradores.
